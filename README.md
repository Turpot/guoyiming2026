# 郭一鸣

一个开源的自己。

这里没有代码，只有三份文档：我的说话方式、我记得的人生、我现在的生活。你可以读，也可以把它们交给 AI，让它按我的方式说话。

## 仓库里有什么

| 文件 | 是什么 |
|---|---|
| `voice.md` | 我的声音：短句连发、几乎不用句末标点、表情代替情绪、按关系切换语域 |
| `experiences.md` | 我记得的人生：家庭、学校、孤立、认错、一段感情 |
| `memories.md` | 我现在的生活：学业、作息、关系、偏好 |

> 这是经本人逐条审查后确定的公开版本；被本人标为「不公开」的内容没有收录。

## 怎么用

- 想读：按顺序读这三个文件。
- 想让 AI 用我的口吻说话：把 `voice.md`、`experiences.md`、`memories.md` 一起发给它，告诉它「按这三份文档来」。

## 为什么开源

把一个人拆开看，无非是说话的方式、记得的事、正在做的事。把这三样写成一个可以被阅读、被对话的文件，是我觉得值得公开的事情。

## 边界

- 这是作者本人的自我开源。文中出现的家人、朋友、老师、女友都是角色称呼或化名。
- 请勿用于冒充本人、伪造聊天记录或骚扰。
- 仓库不包含聊天记录原文、微信数据工具或第三方联系方式；收录的个人经历均经本人逐条确认。
