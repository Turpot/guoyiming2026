# 郭一鸣 2026

一个开源的自己。

每年更新一版。像体检，也像给未来的自己留个存档。

技术栈：一个人。

## 里面有什么

没有代码。没有安装步骤。没有「快速开始」——你已经在开始了。

三份文档：

| 文件 | 是什么 |
|---|---|
| `voice.md` | 我说话的方式 |
| `experiences.md` | 我记得的事 |
| `memories.md` | 我现在在干嘛 |

> 经本人逐条审查。过不了审的删了，留下的按原样。

## 怎么用

- 直接读。读完你可能更了解我，也可能更不了解。
- 或者把三份文档丢给 AI，让它按我的方式说话。学得像不像，看你运气。

## 为什么开源

把人拆开，无非三样：说话的方式、记得的事、正在干的事。

把这三样写成文件扔到 GitHub 上——这大概就是 2026 年的自画像。

明年再拆一次。

## 更新记录

- **2026**：第一次把自己开源。人还活着，精神状态良好（存疑）。

## 边界

- 家人、朋友、老师、女友都是角色称呼或化名。
- 别拿去冒充我、伪造聊天记录、骚扰别人。
- 没有聊天记录原文，没有微信工具，没有别人的联系方式。
- 可以用，可以改，可以说「这什么玩意儿」。
