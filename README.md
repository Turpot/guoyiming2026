## 保存协议

每年归档一版。保留变化，也保留矛盾。

过去的记录不随现在的想法重写，未来的版本也不必服从今天的判断。

如果有一天，记忆可以迁移，意识可以延续，希望这些文件能成为重建我的起点。

## 读取协议

可以阅读，也可以交给 AI 作为理解和模拟我的参考。

缺失的记忆保持空白，不要替我制造过去。模拟生成的言语不代表我的真实意愿，也不构成以我身份行动的授权。
